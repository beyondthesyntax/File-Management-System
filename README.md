FILE MANAGEMENT SYSTEM

A command-line File Management System built with Python that allows users to create, read, update, and delete files. The project uses Python's built-in pathlib module to perform basic file and directory operations.

Features
Create Files: Create new files and write content to them.
Read Files: Read and display the contents of existing files.
Update Files: Rename files, overwrite existing content, or append new content.
Delete Files: Remove existing files.
List Files and Folders: Display files and folders in the current working directory and its subdirectories.
Error Handling: Handle common file operation errors.

Technologies Used
Python 3.14
pathlib
File I/O
Exception Handling
Command-Line Interface (CLI)

Getting Started
Prerequisites
-Install Python 3.14 on your computer
-Git installed on your computer (for cloning the repository)

Check your Python installation:
python --version

Installation
1. Clone this repository:
git clone https://github.com/beyondthesyntax/File-Management-System.git

2. Navigate to the project directory
cd File-Management-System

3. Run the program
python main.py

On Windows, you can also use:
py main.py

How to Use
Run the program to display the main menu:

==== FILE MANAGEMENT SYSTEM ====
1. Create file
2. Read file
3. Update file
4. Delete file
5. List files and folders
6. Exit
Enter a number from 1 to 6 and follow the on-screen instructions to perform the desired operation.
